## zbxcli auth remove

Revoke and remove a saved profile

```
zbxcli auth remove <profile> [flags]
```

### Options

```
  -h, --help                       help for remove
      --insecure-skip-tls-verify   Disable TLS certificate verification
      --yes                        Skip the confirmation prompt
```
